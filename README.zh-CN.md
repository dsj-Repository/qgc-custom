## 这是什么

一个个人维护的 QGroundControl 发行版，同时也是 **QGC 商业定制开发服务**的公开作品集。

如果你需要一款地面站完全贴合你的飞机和业务流程，而不是 QGC 默认那套——这正是我提供的服务。

## 服务客户类型

- **行业无人机厂商**（农业植保、工业巡检、测绘、安防、应急）
- **集成商**——交付完整无人机解决方案的方案商
- **科研院校实验室**——需要定制化任务流程的研究团队
- **自研飞控厂商**——将 QGC 作为配套地面站交付的硬件公司

## 能做什么

### UI 与品牌定制
- 自定义 QML 视图、控件、工具栏
- 完整 UI 换皮（主题、Logo、启动画面、安装包）
- 平板端布局优化（Android / iPad）

### 协议与遥测
- 自定义 MAVLink 消息和方言（Dialect）
- 多机/集群管理
- 自定义数据链路对接（4G/5G、网状电台、卫通）
- 遥测数据上云对接

### 任务规划
- 行业专用任务类型（航测、植保喷洒、巡检模式等）
- 电子围栏、禁飞区、安全逻辑
- KML / GeoJSON / Shapefile 导入导出
- 离线地图瓦片管线

### 载荷与系统集成
- 云台、相机、传感器控制
- AI 推理叠加（目标检测、语义分割）
- 实时视频流传输与录制
- 后端/机群管理平台对接

### 平台与构建工程
- **Qt 5 → Qt 6 迁移**（QGC 二次开发常见痛点，我已解决多次）
- Windows MSI 安装包打包 + 代码签名
- Android 平板构建管线
- GitHub Actions CI/CD 配置
- 性能调优（如航点 UI 卡顿优化等已落地）

## 为什么选我

- **现役 Qt 6.x 开发经验**——大多数 QGC 二次开发者仍停留在 Qt 5
- **Windows + MSVC 2022 工具链熟练**——QGC 最难搞的构建目标之一
- **嵌入式背景**——同时做 MCU + RTOS 固件开发，能从飞控固件到地面站 UI 全栈调试
- **硬件条件齐备**——能用真实 PX4 / ArduPilot 飞机联调，不只是仿真器
- **AI 辅助开发工作流**——同样工作量交付更快，成本对客户更优
