# Contributing / 参与贡献

[English](#english) · [中文](#中文)

---

## English

This is primarily a **personal portfolio repo** for QGroundControl customization services. Contributions are welcome but limited in scope:

### What works well as a contribution

- Bug fixes for code that has been published to this repo
- Documentation improvements (especially translations or clarifications)
- Suggesting case studies or topics worth writing about

### What is **not** in scope

- Feature requests for free implementation (please use the [service-inquiry](.github/ISSUE_TEMPLATE/service-inquiry.md) flow instead)
- Pull requests adding large new features without prior discussion

### How to contribute

1. Open an issue first to discuss the change
2. For code: fork → branch → PR with a clear description
3. Code style follows upstream QGroundControl conventions (Qt / C++17)

## 中文

本仓库主要是 **QGC 定制开发的个人作品集**，欢迎贡献，但范围有限：

### 适合提交的贡献

- 已公开代码中的 Bug 修复
- 文档改进（特别是翻译或语义澄清）
- 建议值得写成案例的主题

### **不适合**的内容

- 期望我免费实现功能（请走 [服务咨询 Issue](.github/ISSUE_TEMPLATE/service-inquiry.md) 流程）
- 未经讨论就直接提交大型功能 PR

### 如何贡献

1. 先开 Issue 讨论改动方向
2. 代码：fork → 分支 → PR，说明清楚改动目的
3. 代码风格沿用上游 QGroundControl 规范（Qt / C++17）
